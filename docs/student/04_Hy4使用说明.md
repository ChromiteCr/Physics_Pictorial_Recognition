# 04 Hy4 提示词包：怎么跑，怎么交回 responses.jsonl

Hy4 没有 API，所以由你在能用的 Hy4 界面里手动跑。它是蒸馏的教师之一：只有和物理引擎判定一致的回答才会被留下，
所有教师合起来最多留 5,248 条。你不需要判断回答对不对，也不要改它。

## 你会拿到什么

开发者导出的一个文件夹（名字类似 `hy4_pack_<日期>`），里面有：

- `README.md`：这个包的简短规则（和本文一致；两者冲突时以包里的 README 为准，并告诉开发者）；
- `prompts.jsonl`：一行一道题，格式是 `{"id": "...", "task": "...", "messages": [{"role": "system", "content": "..."}, {"role": "user", "content": "..."}]}`。

题目里只有合成的实验数据，没有任何人的信息。

## 跑的规则（"盲做"）

1. **每道题开一个新对话。** 不能在同一个对话里连续问几道题，前面的题会影响后面的回答。
2. **原样发送。** system 的内容放进"系统提示 / 自定义指令"的位置，user 的内容作为用户消息，一个字都不加、不删、不改。
   界面没有系统提示的位置时：把 system 原文放在用户消息最前面，空一行再接 user 原文，并在 `run_info.json` 里写
   `"system_mode": "merged_into_user"`（训练时的提示要和教师看到的一致，开发者需要知道你是怎么发的）。
3. **关掉联网搜索、插件和任何工具。** 温度等参数用默认值。可以开思考，但只复制最终回答，不复制思考过程。
4. **每道题只问一次。** 不要因为回答看起来不好就重问或追问（这会让留下来的样本有偏）。
   只有出错（网络断了、界面报错、回答被截断）时才在新对话里重发同一道题，并在 `run_info.json` 的 `notes` 里记下题号。
5. **不给提示。** 不告诉 Hy4 答案应该是什么，不给它看引擎的结果，也不要加"请仔细想想"之类的话。
6. **不用把所有题都跑完。** 开发者会告诉你这一包大概要跑多少道；时间不够就停，交回已经跑完的部分。

## 交回什么

在同一个文件夹里放两个文件：

**responses.jsonl**：一行一道题，`{"id": "和 prompts.jsonl 里一样的 id", "text": "Hy4 的完整最终回答"}`。
回答里的换行要按 JSON 转义（用下面的命令写，就不用自己处理）。

**run_info.json**：这一包是怎么跑的（不写任何人的信息）：

```json
{"model": "Hy4（界面上显示的完整版本名）", "interface": "网页 / 桌面客户端 / 其他", "dates": "2026-11-06 至 2026-11-07",
 "thinking": "开 / 关", "web_search": "关", "system_mode": "system 或 merged_into_user",
 "n_done": 0, "notes": "出错重发过的题号等"}
```

跑完告诉开发者。开发者用 `lab_detective/training/distill.py` 的 `import_responses` 读回来，用和 DeepSeek 一样的规则过滤
（只留和物理引擎判定一致的回答），保留下来的才会进训练包，来源标成 `distill-hy4`。这些记录也要写进 AI 使用台账和 Form 2A。

## 几条方便的命令（在 Mac 终端里，先 `cd` 到这个包的文件夹）

看第 `<id>` 道题的 system 和 user 原文（分别复制）：

```bash
python3 -c '
import json, sys
r = [json.loads(l) for l in open("prompts.jsonl") if l.strip() and json.loads(l)["id"] == sys.argv[1]][0]
for m in r["messages"]:
    print("=====", m["role"], "=====")
    print(m["content"])
    print()
' <id>
```

把剪贴板里 Hy4 的最终回答追加成一行（把 `<id>` 换成题号）：

```bash
pbpaste | python3 -c 'import json,sys; print(json.dumps({"id": sys.argv[1], "text": sys.stdin.read().strip()}, ensure_ascii=False))' <id> >> responses.jsonl
```

交回前检查一遍（每行都是合法 JSON、没有重复、id 都在题目里）：

```bash
python3 -c '
import json
ids = [json.loads(l)["id"] for l in open("prompts.jsonl") if l.strip()]
got = [json.loads(l)["id"] for l in open("responses.jsonl") if l.strip()]
print("题目", len(ids), "已答", len(got), "重复", len(got) - len(set(got)), "不认识的 id", sorted(set(got) - set(ids))[:10])
'
```

检查报错（某一行不是合法 JSON）时，打开 `responses.jsonl` 删掉那一行，用上面的命令重新追加。
