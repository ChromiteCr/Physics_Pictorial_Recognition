### 1. 公共约定（两个实验都适用）

**读数模型。** 学生记录的每个读数 = 均值 + 高斯噪声（标准差 σ），再按仪器分辨率 d 四舍五入。
推断时把"高斯 + 取整"近似为一个标准差为 s = √(σ² + d²/12) 的高斯。

**参数的两类。**
- 线性参数 θ（例如未被抵消的阻力、遮光片真实宽度）：读数均值写成 c + U·θ，θ 有独立的高斯先验 N(m₀, s₀²)。
  对 θ 解析积分：线性高斯模型的边际似然。
- 其他参数（故障幅度、没有记录的装置参数）：放在网格上按先验权重求和。网格规则：
  - uniform(lo, hi, n)：把 [lo, hi] 等分成 n 段，取每段中点，权重相等；
  - loguniform(lo, hi, n)：按几何等比把 [lo, hi] 分成 n 段，取每段几何中点，权重相等；
  - sym_uniform(lo, hi, n)：在 [lo, hi] 上取 n/2 个等分段中点，再加上它们的相反数，共 n 个点，权重相等；
  - point(v)：只有一个点 v。

**原因的证据与后验。** 原因 c 的证据
Z_c = Σ_网格点 g w_g · ∫ Π_i N(v_i ; c_i(g) + U_i(g)·θ, s_i²) · N(θ ; m₀, diag(s₀²)) dθ，
后验 P(c | 数据) ∝ P(c) · Z_c，原因先验 P(c) 在候选原因之间均匀。似然用读数的原单位写高斯密度（包含 −ln(s√(2π)) 这一项）。

**期望信息增益（EIG）。** 已有数据 D、候选原因集合 C、一项追加测量 X（它的读数是 y）：
EIG(X) = Σ_c P(c|D) · Σ_y p(y | c, D) · log₂[ P(c | D, y) / P(c | D) ]，
其中 p(y | c, D) 是在原因 c 下、对 c 的参数按 P(参数 | c, D) 平均后的预测分布；
y 按真实的"高斯 + 取整"生成（y 只取分辨率的整数倍），更新后验 P(c | D, y) 时用上面的高斯近似。
单位是比特。EIG 等于做完 X 之后原因后验熵的期望下降量，永远 ≥ 0。

g 取 9.8 m/s²。

### 2. 探究加速度与力的关系（牛顿第二定律）

**装置和做法。** 长木板一端装定滑轮，另一端垫高以平衡摩擦力；小车（含车上砝码）质量 M = 0.500 kg（学生称出并填写）。
细线跨过定滑轮挂小盘，小盘和槽码总质量 m 依次取 10、20、30、40、50 g。打点计时器测小车加速度 a，
σ = 0.015 m/s²，d = 0.01 m/s²。（另一种计时方式是光电门：σ = 0.006 m/s²，d = 0.001 m/s²。）
记录的"拉力"F = m·g。作图：横轴 F，纵轴 a；理想直线 a = F/M，斜率 1/M 已知，截距 0。

**建模约定。** "只有随机误差"取课本理想模型 a = F/M（细线拉力等于 mg、阻力被完全抵消、滑轮和车轮的转动惯量可忽略）。
真实装置里连接体效应 a = mg/(M + m) 总是存在，所以它单独作为一个原因（"槽码质量没有远小于小车质量"）；
其余每个故障原因 = 精确连接体动力学 + 一个被忽略的效应或一个操作错误。

**各原因下主测量的均值**（m 用 kg）：

| 原因 | 物理过程 | 均值 a | 参数与先验 |
|---|---|---|---|
| 只有随机误差 | 理想模型 | a = mg/M | 无 |
| 没有平衡摩擦力或平衡不足 | 沿板方向合力里多了未被抵消的阻力 F_res（负值） | a = (mg + F_res)/(M + m) | F_res 线性参数，N(−0.05, 0.015²) N |
| 平衡摩擦力过度 | 重力沿板的分力超过阻力，多出 F_res（正值） | a = (mg + F_res)/(M + m) | F_res 线性参数，N(+0.05, 0.015²) N |
| 槽码质量没有远小于小车质量 | 小车和槽码一起加速，细线拉力小于 mg | a = mg/(M + m) | 无 |
| 细线与木板不平行 | 细线与木板成 φ 角，φ 在运动中视为不变 | a = mg·cosφ/(M + m·cos²φ) | φ 网格 uniform(8°, 25°, 18) |
| 滑轮转动惯量和轴摩擦 | 滑轮两侧拉力差带动滑轮和车轮转动并克服轴摩擦 f_p；J 是等效质量 Σ I/r² | a = (mg − f_p)/(M + m + J) | J 网格 uniform(5, 25, 16) g；f_p 线性参数，N(0.02, 0.006²) N |

细线斜拉那一行的推导要点（请核对）：沿板方向小车 M·a = T·cosφ；细线收短的速率是 v·cosφ，所以槽码的加速度是 a·cosφ，
m·(a·cosφ) = mg − T。细线拉力的垂直分量会让正压力变小、阻力略减，这一项按二阶小量略去。

**追加测量。**
- 不挂细线、轻推小车测它自己的加速度 a₀（σ、d 同主测量）：平衡不足或过度时 a₀ = F_res/M；其余原因 a₀ = 0。
- 量细线两端离木板的高度差 Δ（cm；σ = 0.2 cm，d = 0.1 cm）：小车挂钩到滑轮顶端的水平距离 40 cm，
  细线斜拉时 Δ = 40·tanφ；其余原因 Δ = 0。
- 在 m = 10 g 或 50 g 处重复测一次主测量。

### 3. 验证机械能守恒定律（小车沿倾斜轨道下滑，光电门）

**装置和做法。** 轨道一端垫高、倾角 θ 固定且不记录。小车上装遮光片，学生算速度时用标称宽度 d₀ = 10 mm；
遮光片真实宽度 w 是所有原因共用的线性参数，N(10.00, 0.02²) mm。小车（含遮光片、车轮）质量 0.30 kg。
从光电门上方竖直高度 h = 5、10、15、20、25 cm 处由静止释放，读挡光时间 Δt（ms；σ = 0.025 ms，d = 0.1 ms）。
Δt = w/v（w 用 mm、v 用 m/s 时 Δt 的单位正好是 ms）。学生算 v_rec = d₀/Δt。
作图：横轴 g·h（J/kg），纵轴 ½·v_rec²（J/kg）；理想直线斜率 1、截距 0。
没有记录的倾角 θ 只在需要它的原因里出现，网格 uniform(12°, 30°, 19)。

**各原因下测速点真实速度的平方 v²**（h 用 m）：

| 原因 | 物理过程 | v² | 参数与先验 |
|---|---|---|---|
| 只有随机误差 | 机械能守恒 | v² = 2gh | 无 |
| 遮光片宽度用错了 | 真实宽度 = w + w_err，学生仍用 d₀ | v² = 2gh；Δt = (w + w_err)/v | w_err 线性参数，N(0, 0.4²) mm |
| 把斜面上的距离当成了下落高度 | 记录的 h 其实是沿轨道的距离 s | v² = 2g·h·sinθ | θ 网格 |
| 轨道和车轮之间有摩擦 | 等效滚动阻力系数 μ，滑过距离 h/sinθ | v² = 2gh·(1 − μ·cotθ) | μ 网格 loguniform(0.004, 0.03, 25)；θ 网格 |
| 车轮转动分走了动能 | 车轮转动动能占平动动能的比例 ε | v² = 2gh/(1 + ε) | ε 网格 uniform(0.015, 0.08, 27) |
| 高度量到了错误的位置 | 记录高度 = 真实高度 + δ | v² = 2g·(h − δ) | δ 网格 sym_uniform(0.5, 4.0, 36) cm |
| 释放时推了小车 | 出发时已有速度 v₀ | v² = 2gh + v₀² | v₀ 网格 uniform(0.2, 0.6, 21) m/s |

所有原因下 v² 都截到不小于 10⁻⁶。车轮那一行的推导要点（请核对）：4 个均匀圆盘车轮总质量 m_w，纯滚动，
转动动能 = ¼·m_w·v²，所以 ε = m_w/(2M)，M 为含车轮的总质量。

**追加测量。**
- 用游标卡尺测遮光片宽度（mm；σ = 0.01，d = 0.02）：读数 = 真实宽度（遮光片宽度原因下是 w + w_err，其余是 w）。
- 用铅垂线重测 25 cm 那次的竖直高度（cm；σ = 0.05，d = 0.1）：斜面距离原因下 = 25·sinθ；高度位置原因下 = 25 − δ；其余 = 25。
- 把轨道调水平，轻推小车测滑行减速度（m/s²；σ = 0.01，d = 0.001）：摩擦原因下 = μ·g；其余 = 0。
- 用细线拴住小车、剪断细线释放，在 5 cm 和 15 cm 处重测：释放推车原因下 v₀ = 0，其余原因与主测量相同。
- 小车上加 0.50 kg 配重，在 15 cm 和 25 cm 处重测：车轮原因下 ε' = ε·0.30/(0.30 + 0.50)；摩擦系数 μ、宽度误差不变。

### 4. 两原因 EIG 例子（牛顿第二定律，打点计时器，M = 0.500 kg）

只考虑两个候选原因：A = "槽码质量没有远小于小车质量"，B = "细线与木板不平行"，先验各 1/2。
基础数据 D（m 单位 g，a 单位 m/s²，已取整到 0.01）：

| m | 10 | 20 | 30 | 40 | 50 |
|---|---|---|---|---|---|
| a | 0.19 | 0.37 | 0.56 | 0.72 | 0.87 |

三项候选追加测量：
- X1：量细线两端离木板的高度差 Δ；
- X2：在 m = 50 g 处重复测一次加速度；
- X3：不挂细线、轻推小车测 a₀。

请算：
1. ln Z_A、ln Z_B（按第 1 节的约定，B 对 φ 的 18 个网格点求和），以及 P(A|D)、P(B|D)；
2. EIG(X1)、EIG(X2)、EIG(X3)（比特），y 按取整后的离散值精确求和（不要用蒙特卡洛作主结果）；
3. 用你自己的蒙特卡洛（≥ 20,000 个样本）再算一遍 EIG(X2)，报告估计值和它的标准误；
4. 用一两句话说明 EIG(X3) 为什么是这个值。
