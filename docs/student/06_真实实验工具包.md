# 06 真实器材实验（E5）工具包：从随机表到分析

工具包在 `lab_detective/fieldkit/`，全部离线运行。几条底线：

- **只有你测量和记录。** 在场的成年人只负责安全监督，并按密封卡做一项准备动作。
- **不记录任何关于人的信息。** 记录表、清单、结果里都没有名字；不拍照、不录像。
- **会损坏器材的故障一律不做。** 弹簧超过弹性限度只在模拟里做；"再挂一组 350 g"默认不做（见 02 第五节）。
- 下面的命令都在仓库根目录、用 `.venv/bin/python` 运行。

## 1. 实验课之前：生成随机表

先把 `02_你要做的决定.md` 第五节定完，再生成：

```bash
.venv/bin/python -m lab_detective.fieldkit.schedule build --out field_kit
# 可选：--experiments hooke,newton2,pendulum   --repeats 2   --sessions 2
#       --config newton2.cart_mass_g=480 friction.board_length_m=1.2   --twin-eig
#       --analysis wilcoxon_alternative=two-sided alpha=0.05   --atlas confused_below=0.75 separable_at=0.9
#       （--analysis 和 --atlas 后面的值都是 02 第五节里你定的；上面的数字只是占位）
```

最好请成年人在场时运行（种子用系统随机数，只存在密封表里）。生成后：

- 屏幕上打印两个哈希：**公开表文件的 sha256** 和**承诺值**（密封表的 sha256）。两个都抄进研究计划，写上日期。
- `field_kit/sealed/` **整个交给成年人**，你不要打开。成年人用浏览器打开 `sealed_cards.html` 打印，
  沿虚线剪开、沿点线对折，装进信封，信封上抄外页的代码。卡片第一页是给成年人的须知。
- `field_kit/public/` 是你的：`run_list.md`（运行顺序、代码、每次的追加测量顺序）、`runs/`（每次运行一个记录表）、
  `templates/`（每个实验一个空白模板）、`schedule_public.json`（公开表，里面写着预先规定的分析规则）。
- 屏幕上如果有"所选条件里没有图谱判为混淆的一对"的提示，看完再决定要不要换条件、重新生成（重新生成要用新的种子，
  旧的两张表作废并记进实验记录本）。

## 2. 每次运行

1. 把这次的记录表从 `field_kit/public/runs/` 复制到你的数据文件夹（例如 `field_data/`），用文本编辑器或 Numbers 打开。
   只改 `value` 列（以及基础方案里你实际量到的 `setting`），其他列、以 `#` 开头的行都不要动。
   表头里写着 `config.` 的仪器配置（例如小车质量）按你实际称量的值改。
2. 把信封交给成年人，等他说可以开始。
3. 按记录表顶部写的"基础方案"做完，填好基础方案那几行的读数。
4. 运行（不需要联网）：

   ```bash
   .venv/bin/python -m lab_detective.fieldkit.live field_data/<这次的文件>.csv --public field_kit/public/schedule_public.json
   ```

   它会把"信息增益推荐"那一项测量填进记录表，在旁边留一个 `.eig.json` 回执，并按顺序列出接下来要做的追加测量。
   屏幕上只有动作，没有引擎的猜测。推荐和"最佳固定测量"或"简单重复"恰好相同时只做一次。
5. 按列出的顺序做追加测量，填读数。实在做不了的（例如铁架台不够高）在 `value` 填 `skip`。
6. **运行 live 之后不要再改基础方案的读数。** 回执里记着基础读数的指纹，改了会在检查时报错。
   真的记错了，不要改，在实验记录本里写清楚，告诉开发者。

## 3. 全部做完：检查和冻结

```bash
.venv/bin/python -m lab_detective.fieldkit.ingest check  field_data --public field_kit/public/schedule_public.json
.venv/bin/python -m lab_detective.fieldkit.ingest freeze field_data --public field_kit/public/schedule_public.json
```

- `check` 只报告问题，不改文件。"错误"会阻止冻结（例如缺读数、单位被改、代码对不上）；"提示"只是提醒。
  修错误时只能修抄写问题（例如把 `1,2` 改回 `1.2`），每一处都记进实验记录本。
- `freeze` 在数据文件夹里写 `FIELD_MANIFEST.json`，里面是每个记录表和回执的 sha256。把这个文件的 sha256 和日期抄进实验记录本。
  之后任何改动都会被发现。没做的运行会被列出来，分析时如实报告。

## 4. 拆封和分析（你本人启动）

冻结以后，请成年人把 `sealed/` 文件夹和所有信封交还给你，然后在终端里自己运行：

```bash
.venv/bin/python -m lab_detective.fieldkit.analysis --public field_kit/public/schedule_public.json \
    --sealed field_kit/sealed/schedule_sealed.json --data field_data --out field_results
```

它会先核对：数据冻结后没被改过；密封表就是当初承诺的那一张；用种子重算的分配和两张表一致。任何一项不通过就停止。
然后要求你输入确认语，才开始算。输出：

- `field_results/analysis_tables.md`：各阶段的正确率和区间、配对 Wilcoxon、图谱最难分开那一对的单独报告、
  图谱预测效度、误报、失配、没做的运行；
- `field_results/analysis_results.json`：每次运行、每个引擎的全部数字。

结果里只有数字，没有解读。解读、结论和局限都由你本人写。单摆这一组用"其他实验"通道分析，同时附上留出单摆孪生的结果作对照；
比例类的故障在"其他实验"通道里斜率未知时看不出来，按"等价于只有随机误差"计，表里会标出来。

## 5. 出了意外怎么办

- 某次运行做到一半停了：如实记录，记录表照样交给 `check`；做不完的运行不补做别的条件。
- 顺序做乱了、卡片拆错了、成年人多做或少做了动作：不要补救，写进实验记录本，分析后在报告里列出，偏离计划的写 Addendum。
- 任何时候觉得不安全：立刻停下。
