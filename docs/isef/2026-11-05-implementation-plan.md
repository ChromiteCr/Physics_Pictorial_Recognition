# 实验侦探（Lab Detective）：ISEF 升级实施计划

## Context

**为什么要改**
- 项目这一轮没有获奖。
- 老师的意见：技术上要在大模型或视觉模型上真正动刀；实践和项目闭环是可以提前拿到的分。

**要做成什么**：一个完全离线的"实验侦探"。
- 找出学生力学数据背后的系统误差来源。数据不足以区分时直接说明，并推荐最能把各原因区分开的下一次测量。

## 3. 三条科学主线

具体阈值由你在研究计划里定。

- **A 可辨识性图谱**：作为预先规定的定量成果交付，回答两件事：课本标准方案下哪些原因根本分不开；哪一次测量能把它们分开。E5 用来检验图谱的预测效度。
- **B 闭环里的下一次测量**（确认性）：比较 EIG 自适应选择和最佳固定追加测量。模拟部分在高保真世界里做，真实部分用课内实验的 E5，两者都用配对 Wilcoxon。
- **C 模型迁移**（确认性，主要的机器学习主张）：
  - 闸门检验：在 6 个留出实验上比较 S1 和打乱标签对照，用精确 McNemar。
  - 总效应：S1 和 3-shot 基线的差距。
  - 双侧检验，零结果照样报告。
  - top-1 准确率在等价类上计算。
  - 跨实验用精确符号检验，并如实写明 n = 6 时这个检验的局限。
- **对照**：K0 到 K6。
- **工程指标**：EC1 到 EC7。
